# AGENTS.md

Instructions for coding agents working in this repository (Codex, Claude Code and others)
live in **`CLAUDE.md`** at the repository root. Read that file in full before making any
change here; everything in it applies to you regardless of which agent you are.

Highlights you must not skip:

- Trunk-based development on `main`; commit freely, never push without explicit approval.
- Conventional-Commits messages written for players (the Nexus Mods changelog is generated
  from them). No chat or session links in commit messages.
- Do not use the em dash character anywhere in this repo.
- `docs/PROGRESS.md` is the running session log; read it first when resuming editor work.
