# Abiotic Editor field guide

Welcome, lab personnel. **Abiotic Editor** helps you look after an **Abiotic Factor** save: recover a misplaced item, tidy a character inventory, inspect a troubled world, or repair a save layout.

It is a fan-made tool that works with files you choose on your own computer. Start here if you want to play, not program.

> **Safety notice:** Close the game before ordinary file edits. Keep your own copy of the save first. The desktop app also makes a `.bak` copy when it saves.

## What you can manage

- **Personnel records:** inventory, equipment, skills, recipes, needs, appearance, and GatePal entries.
- **Facility records:** containers, dropped items, pets, NPCs, doors, resource nodes, vehicles, and story progress.
- **Recovery work:** compare saves, move supplies, update server settings, and repair Game Pass save containers.

The [player documentation](https://christophervr.github.io/AbioticEditor/guide/) is the main handbook, with plain-language guides for each route.

## Plugin corner

This wiki also keeps the short reference for community plugins. Plugins can add optional tools to Abiotic Editor. Only install a plugin from someone you trust: a plugin can do the same things on your computer as the editor itself.

- [Adding Plugins](Adding-Plugins) - install and use a community plugin.
- [Building Plugins](Building-Plugins) - create one in .NET or JavaScript.
- [Plugin API Reference](Plugin-API-Reference) - look up the available building blocks.

For examples, see the [sample plugins](https://github.com/ChristopherVR/AbioticEditor/tree/main/plugins). The [technical reference](https://christophervr.github.io/AbioticEditor/reference/) has the deeper developer material.
